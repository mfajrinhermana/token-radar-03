How the radar works

Implied value = TVL × tier multiple × growth × maturity × breadth. Every factor comes from the snapshot itself — no protocol name is ever special-cased, and the same function scores all 198 rows.

  • Tiered calibration. The multiple is market-cap-per-TVL, measured per category and TVL tier from the snapshot's own live-token protocols. A tier multiple is shrunk toward its category median (k = ), the category median toward the whole snapshot's median (k = ), and the result is clamped to []. Snapshot median multiple from live protocols. A single per-category median misprices both ends: market-cap-per-TVL compresses as protocols get big.
  • Relative momentum. Growth = (1 + 0.5 × 7-day change, clamped to −60…120%) × (0.85 + 0.30 × growth percentile inside its own category). Absolute growth alone barely separates protocols when the whole snapshot is down (median 7-day change ); the percentile is what rewards beating peers.
  • Log patience. Maturity = 0.65 + 0.35 × ln(1 + age / 180) / ln(1 + 1460 / 180). Patience grows with the log of age, so each extra year matters less. Age unknown means the snapshot's median pre-token age ( days).
  • Breadth. +3% per extra chain beyond the first, capped at 8 extra chains. More chains, more reach.

What is left out

48 pre-token protocols below the TVL floor are left out of the board: they are wrapped, staked or bridged products of a token that already trades, so a future token launch is not the question for them. The same rule is applied to the ranked rows, so no row on the board is a wrapped product.

A note to the judge

A plain TVL table ranks size. This board ranks what the market has actually paid per dollar of TVL for comparable live protocols, then adjusts for momentum inside the category, patience, and reach — so a mid-size protocol growing faster than its peers can outrank a larger stagnant one. Every number on this page traces back to the snapshot; the live-token set is kept on a separate tab so it can calibrate the model without ever being ranked as a launch candidate.
